# Security Policy

## Reporting a Vulnerability

Report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/MarcinWolnyEU/Staan-MCP/security/advisories/new):

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability** (or use the
   [new advisory form](https://github.com/MarcinWolnyEU/Staan-MCP/security/advisories/new)
   directly).
3. Provide a clear description, reproduction steps, and the affected version.

The maintainer (MarcinWolnyEU) will receive and triage the report. Do not open public issues, discussions, or pull requests for security problems, as this may expose users before a fix is available.

## Response Time

Reports are acknowledged within a few business days. You will receive updates as the issue is investigated and a fix is prepared.

## Coordinated Disclosure

Disclosure is coordinated through the
[GitHub Security Advisory](https://docs.github.com/en/code-security/security-advisories) for this
repository. Reporters who wish to be credited will be acknowledged in the published advisory once a
fix is released.
